# Partdro Products

Independent Nuxt 4 product and supplier directory powered by the Partdro Supabase catalogue.

## Stack

- Nuxt 4 / Vue 3 / TypeScript
- Supabase PostgreSQL as the source of truth
- Cloudflare Pages deployment

## Security

Only public, approved catalogue records should be exposed to visitors. Never put a Supabase service-role key in client-side code.
